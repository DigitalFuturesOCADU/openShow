As part of my undergrad thesis on computational typography and creative tools, I'm currently exploring applications of AI in typeface design. I created a tool that allows you to enter text and "decorate" it, using Python Imaging Library, Stable Diffusion, Gradio, and Hugging Face Spaces. This can be used for generating font ideas, expressive typography, or anything else. The base font is one I designed a few months back called Dimple Sans (I haven't publicly released it yet, as I'm still refining it!), but soon I would like to add the ability for custom uploaded fonts. Using my text decorator tool, I made an alphabet using prompts based on each individual letter.
