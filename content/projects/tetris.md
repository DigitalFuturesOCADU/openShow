This game is based on Tetris. I used to play this game many times but now I cannot really find it anywhere. There are other versions of Tetris but there not the original type. I decided that for my final comp-sci assignment, I will do some research and code a Tetris game. It was hard at first to actually get the right one but eventually, I found it. The game is straightforward; once you see the falling bricks, use the arrow keys to rotate it before it hits the ground.
