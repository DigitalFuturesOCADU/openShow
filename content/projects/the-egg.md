" THE EGG project is an immersive interactive storytelling installation with a poetic approach to the creation story. This project was formed based on a previous artist's experience ""My body, My land""(2019) photo collage series. 
   
 Inspired by the Margaret Atwood story “Madd Addam”(2014), and a childhood dream this interactive installation is trying to create an abstract imaginary environment of the inside of The Egg(womb). where every single creature was there once, but can’t remember it anymore.

 This experiment was created with the use of technologies like Digital photography and collage, physical computing, an Arduino controller board and TouchDesigner software.

This immersive abstract illustration will be projected inside a curve-shaped, human-sized environment to embrace each audience who enters this space. this place will be almost dark at first. Audiences who enter this dark place will see just 3D rounding eggs on the screen and hear the sound that is telling the story. if they get curious about what they are hearing, they can see inside the egg using a provided flashlight and embedded light sensors(Arduino circuit) around this space."
